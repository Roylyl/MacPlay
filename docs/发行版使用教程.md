# MacPlay1.2.3发行版使用教程（构建38）

MacPlay将iPhone的CarPlay画面、声音和操作接入Mac，支持USB直连与无线连接。

[项目主页](https://github.com/Roylyl/MacPlay) · [下载安装包](https://github.com/Roylyl/MacPlay/releases) · [本版更新内容](RELEASE-1.2.3.md)

## 安装与更新

要求macOS14及以上。在“苹果菜单→关于本机”查看芯片信息，并在发行页选择对应安装包：

| Mac | 安装包架构 |
| --- | --- |
| AppleM系列 | `arm64` |
| Intel | `x86_64` |

打开DMG，将MacPlay拖入“应用程序”后启动。如果系统拦截，在“系统设置→隐私与安全性”中确认打开。当前安装包采用本地签名，未经过Apple公证。

首次安装自动准备内置实验性认证材料，默认1280×720、60fps，优先使用内建显示器，严格物理像素显示默认关闭。更新时先退出旧版再替换，原有设置、配对与本机认证文件保留。

在“连接→应用”选择跟随系统、简体中文、繁體中文或English；默认跟随Mac系统。CarPlay内部语言跟随iPhone。

## 有线CarPlay

1. 用USB数据线连接iPhone与Mac，解锁iPhone，完成“信任此电脑”。
2. 在MacPlay“连接”页选择“有线CarPlay”，多台设备接入时选择目标iPhone。
3. 点击“启动接收”，按iPhone提示确认，等待CarPlay画面出现。有线连接无需填写Wi-Fi信息。

可开启“连接→应用→USB接入时自动启动CarPlay”，在MacPlay运行时插入iPhone自动启动有线接收；指定设备后只响应该iPhone。首次连接仍需解锁并完成信任。

## 无线CarPlay

1. Mac和iPhone接入允许设备互访的同一局域网，在MacPlay选择“无线CarPlay”。Mac可使用Wi-Fi，也可通过以太网连接同一路由器。
2. 网络接口默认自动选择。需要指定网卡时改为手动选择，后续刷新会保留该选择；设备未连接时会显示状态。
3. Mac使用Wi-Fi时，点击“读取当前网络”并允许定位权限。Mac使用以太网时，手动填写iPhone连接的Wi-Fi名称、共享密码和实际信道。
4. Wi-Fi密码可以手动填写，也可点击“读取已保存密码”并按macOS钥匙串提示授权。读取过程中新填写的内容不会被迟到的读取结果覆盖。
5. 打开蓝牙设置，在iPhone上选择Mac的系统名称，在两端确认配对码。
6. 选择目标iPhone，点击“启动接收”或“应用并重新连接”，在iPhone上确认CarPlay提示。

MacPlay不会创建名为MacPlay的Wi-Fi。所选网络接口需有可用IPv4或链路本地IPv6地址，路由器须允许两端互访。使用以太网时，所填无线参数属于iPhone连接的Wi-Fi，而不是网卡名称。企业802.1X和网页登录凭据不适用于此握手方式，可使用个人Wi-Fi或USB连接。

读取失败时，在按钮下方查看原因与系统状态码，或直接手动填写。同一SSID读取失败保留已有密码；SSID变化时清除旧密码，避免连接到新网络时仍使用旧凭据。

启动无线连接前，MacPlay会读取所选Wi-Fi信息并刷新同一SSID的信道与BSSID，不会自动读取密码或触发钥匙串授权。Mac走以太网或需要指定接入点时，可在“连接→共用Wi-Fi→高级网络设置”填写iPhone所在接入点的BSSID；普通使用留空即可。

接收地址优先使用所选网卡的IPv4。若有同接口的链路本地IPv6备用地址，发送参数12秒后仍未收到手机连接时，会自动重试一次。已收到连接或停止接收后不再重试，不会改用其他网卡。

### 无线自动重连

在“连接→共用Wi-Fi”开启“无线连接被动断开时自动重连”。默认关闭，只回连成功连接后被动断开的iPhone，使用上次应用的配置。等待间隔为5、10、20、30、60秒，之后保持60秒。主动停止、确认断开、退出或关闭开关会取消重连；首次连接失败不进入自动重连。

## 显示与智能缩放

在“显示”页选择显示器、分辨率和帧率，更改后点击“应用并重新连接”。默认普通窗口模式自动适配屏幕，可拖动边框等比例调整大小，不改变向iPhone请求的分辨率。

显示器参数在后台读取。严格物理像素显示和“屏幕原生像素（避开刘海）”需要当前屏幕的真实像素及物理尺寸；检测中或读取失败时暂不可选。可刷新后重试，也可先使用普通窗口模式。严格模式固定窗口大小，原生像素模式全屏并避开刘海。

收到首帧解码画面后才显示CarPlay窗口。将鼠标移到画面顶部并停留片刻，使用悬浮标题栏拖动、最小化或关闭窗口。

在CarPlay画面内打开“设置→显示屏→智能缩放显示”。开启后，CarPlay会自动调整图标、文字和实际渲染尺寸；希望按所选像素显示时可关闭。这个设置由iPhone控制，与MacPlay窗口大小分别设置。更改后画面没有更新时，可应用并重新连接。

帧率可选30/60/90/120fps。120fps视频启动协商失败后依次尝试90fps、60fps；90fps失败后尝试60fps。回退只作用于当前连接，实际输出由iPhone、网络和解码能力决定。“显示→流畅度→接收统计”可查看本次尝试、实际接收和解码输出帧率，以及实际视频尺寸。解码帧率不是显示器刷新率，静态画面下数值可能降低。

视频解码停滞或视频通道中断时，MacPlay会尝试请求关键帧、重建解码管线等恢复操作；超过恢复期限后结束本次连接。无线被动断开是否再次连接，仍由自动重连开关决定。

## 音频与控制中心

“音频”页可实时调整媒体与通话音量，默认100%；可选择输入/输出设备，默认跟随系统。切换输入/输出设备即时应用，无需重新连接CarPlay。设备列表随插拔更新，指定设备断开后回退系统默认设备，并恢复需要使用的麦克风。使用Siri或通话麦克风时允许系统权限。音频页可查看当前编码、采样率与声道。

播放歌曲后，可在Mac控制中心查看歌曲、歌手、专辑封面、进度和播放状态。当前播放器提供有效时长并允许跳转时，拖动系统进度条会向iPhone发送跳转请求。直播或播放器未提供跳转权限时，进度条不能拖动。本版不提供独立歌词同步。

## 窗口、后台与退出

主动停止或会话断开后，CarPlay窗口关闭，返回主页面并恢复“启动接收”。点击CarPlay窗口红色关闭按钮会先确认断开；取消后保持连接。点击CarPlay中的MacPlay图标可打开主窗口。

在“连接→应用→关闭主窗口时”选择关闭行为：

- 每次询问：关闭时选择后台运行或退出，可勾选记住选择。
- 保持后台运行：关闭主窗口后继续接收，可从菜单栏打开窗口或退出。
- 退出MacPlay：关闭主窗口时结束接收并退出应用。

首次安装默认每次询问；已有用户更新后保留原来的后台或退出行为。两个窗口共用MacPlay的Dock入口。菜单栏图标提供主窗口、CarPlay窗口、启动/停止接收和退出入口。后台运行不等于开机启动。

## 更新与日志

“关于”页显示版本、构建号和运行架构。点击“检查更新”读取GitHub正式发行版，并按当前Mac芯片选择安装包；通过Rosetta运行时仍优先选择M系列版。

自动检查更新默认开启，每次启动检查一次，持续运行时每两小时静默检查。后台检查结果显示在“关于→软件更新”。点击“下载更新”后通过浏览器下载，退出旧版再替换应用，不自动安装。

在“关于→日志”点击“导出日志”保存TXT，或点击“导出诊断快照”保存JSON。JSON包含版本、运行平台、当前连接与媒体统计、认证准备状态以及日志。导出时过滤密码、密钥内容、IPv4/IPv6地址和常见设备标识，不附带设置文件或认证材料。反馈问题时附上连接方式、发生步骤和导出文件，发送前可自行查看内容。

更多功能与常见问题见[项目README](../README.md)。
