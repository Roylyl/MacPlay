# MacPlay1.2.3

本次更新完善无线连接、视频恢复、音频设备切换和诊断导出，并新增主窗口关闭策略。首次安装仍默认1280×720、60fps，严格物理像素显示默认关闭。

## 更新内容

- 修复快速放大、缩小CarPlay窗口时接收进程崩溃、画面窗口自动关闭的问题，保留等比例窗口缩放。
- 修复长时间拖动窗口后将积压心跳误判为网络断开的情况。
- 修复接收进程意外退出后，继续发送音量、显示画面等命令可能导致主程序退出的问题。
- 停止接收时先停止视频管线，再关闭窗口；取消旧窗口的滚动计时器、残留触控和延迟全屏操作。
- 无线连接优先使用所选接口的IPv4地址；若12秒内未收到手机回连，使用同接口的链路本地IPv6备用地址重试一次。实际连接到达或停止接收后取消重试，不改用其他网卡。
- 启动连接前刷新同一Wi-Fi的信道与BSSID，适应Mesh接入点切换；高级设置支持手动填写BSSID。启动时不会自动读取钥匙串密码或弹出密码授权。
- 视频解码停滞或视频通道中断时，有限次数尝试请求关键帧、重建解码管线等恢复操作，避免一直停留在冻结画面。
- 输入/输出设备支持连接中实时切换；设备列表随插拔刷新，指定设备断开后回退系统默认设备，并恢复需要使用的麦克风。
- 展示实际视频尺寸、当前尝试帧率、接收与解码输出帧率，以及音频编码、采样率和声道；补充音频时序统计。
- 新增JSON诊断导出，与TXT日志一同放在“关于→日志”。导出包含运行信息、媒体统计与日志，增强IPv6、多行密钥和设备信息脱敏。
- 关闭主窗口可选择每次询问、后台运行或退出，并可记住选择。新安装默认询问，更新安装保留原来的关闭行为。
- 音频首包回调与所属连接绑定，避免额外控制连接干扰已经播放的音频，以及Siri或通话的麦克风启动。关闭后的迟到回调不再影响新会话。
- 网络接口默认自动选择，支持手动选择Wi-Fi或以太网接口。刷新网络、切回应用时保留手动选择，接口暂时不可用时显示实际状态。
- Mac通过以太网连接同一路由器时，可填写iPhone所在Wi-Fi的SSID、共享密码和实际信道使用无线CarPlay。
- 改进网络与钥匙串读取：读取过程中修改输入，旧结果不会覆盖新设置；同一网络读取密码失败时保留已有密码，SSID变化时清除旧密码。
- 显示器参数在后台限时读取，避免主窗口等待系统查询；切换或插拔显示器时，不使用过期查询覆盖当前选择。
- 严格物理像素显示和原生像素模式需要已确认的显示器参数，检测中或失败时显示原因。普通窗口模式仍可使用，不再被物理参数读取失败阻塞。
- 改进授权等待和USB自动启动：迟到的授权结果不会覆盖新设置，需要显示器参数时等待检测完成再连接。新设置尚未准备好时保留已有连接。
- 更新README、使用教程和Git忽略规则。

## 安装与更新

按“苹果菜单→关于本机”中的芯片信息选择对应附件：

| 安装包 | 适用设备 |
| --- | --- |
| `MacPlay-1.2.3-arm64.dmg` | AppleM系列Mac |
| `MacPlay-1.2.3-x86_64.dmg` | Intel Mac |

要求macOS14及以上。退出旧版，打开DMG，将MacPlay拖入“应用程序”替换。已有显示设置、配对与本机认证文件保留。首次启动自动准备内置认证文件。

## 开始使用

- USB连接：用数据线连接iPhone并解锁，完成信任，在MacPlay选择有线连接后启动接收。
- 无线连接：两端接入允许互访的局域网，所选接口需有可用IPv4或链路本地IPv6地址。完成蓝牙配对，填写iPhone所在Wi-Fi的SSID、密码和信道后启动接收。Mac默认自动选网卡，也可手动指定；Mac走以太网时，填写的无线信息仍属于iPhone所连Wi-Fi。
- 读取网络与密码：Wi-Fi名称读取需要定位权限，钥匙串读取按系统提示授权。读取结果和失败原因显示在按钮下方；也可手动填写。
- 显示：普通窗口可按比例调整大小。使用严格像素或原生像素模式前，等待显示器检测完成；参数暂不可用时可刷新或先使用普通窗口模式。
- 帧率：30/60/90/120fps为请求值，实际接收和解码帧率在显示页查看。120fps启动失败时依次尝试90fps和60fps。静态画面可能减少视频更新，解码帧率不等于显示器刷新率。
- CarPlay界面大小：在CarPlay画面内打开“设置→显示屏→智能缩放显示”。此开关可改变图标、文字和渲染尺寸，与MacPlay窗口大小分别设置。
- 音频：在“音频”页实时调整媒体/通话音量、切换输入/输出设备。音乐信息和播放操作仍使用Mac控制中心。
- 后台：在“连接→应用”设置关闭主窗口时的行为；菜单栏图标可重新打开主窗口、显示CarPlay或退出。
- 问题反馈：在“关于→日志”点击“导出日志”保存TXT，或点击“导出诊断快照”保存JSON，附上连接方式和具体表现。
