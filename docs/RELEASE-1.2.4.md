# MacPlay1.2.4

本次更新修复无线连接后的重复握手与断线问题，改善改名iPhone识别、连接重试和USB设备选择，并新增“捐赠”页。首次安装默认1280×720、60fps，严格物理像素显示默认关闭。

## 更新内容

- 新增“捐赠”页，提供微信支付、支付宝、AlipayHK收款码和PayPal入口，收款码支持点击放大。
- 修复无线CarPlay连接成功后重复蓝牙握手、再次发送启动请求，可能导致画面关闭和反复断线的问题。
- 正确处理iPhone的CarPlay可用性通知；已建立的网络iAP2通道不再发起新会话。
- 取消蓝牙设备名称必须包含iPhone的限制，改名后的手机也可选择和连接；仍通过iAP2服务识别兼容设备。
- 握手中途断开后释放设备占用，避免旧会话阻挡后续连接；旧控制连接和事件通道不会清除新会话的状态。
- 蓝牙服务查询超时后允许再次尝试，及时释放旧通道资源，避免长时间使用后无法重连。
- 关闭无线自动重连开关时，保留正在进行的手动连接。
- 自动选择设备时支持从无线切换到当前接入的USB手机；插拔其他手机不再覆盖正在运行的连接状态。

## 安装与更新

按“苹果菜单→关于本机”中的芯片信息选择对应附件：

| 安装包 | 适用设备 |
| --- | --- |
| `MacPlay-1.2.4-arm64.dmg` | AppleM系列Mac |
| `MacPlay-1.2.4-x86_64.dmg` | Intel版Mac |

要求macOS14及以上。退出旧版，打开DMG，将MacPlay拖入“应用程序”替换。已有显示设置、配对与本机认证文件保留。首次启动自动准备内置认证文件。

## 开始使用

- USB连接：用数据线连接iPhone并解锁，完成信任，在MacPlay选择有线连接后启动接收。
- 无线连接：两端接入允许互访的局域网，所选接口需有可用IPv4或链路本地IPv6地址。完成蓝牙配对，填写iPhone所在Wi-Fi的SSID、密码和信道后启动接收。Mac默认自动选网卡，也可手动指定；Mac走以太网时，填写的无线信息仍属于iPhone所连Wi-Fi。
- 读取网络与密码：Wi-Fi名称读取需要定位权限，钥匙串读取按系统提示授权。读取结果和失败原因显示在按钮下方；也可手动填写。
- 显示：普通窗口可按比例调整大小。使用严格像素或原生像素模式前，等待显示器检测完成；参数暂不可用时可刷新或先使用普通窗口模式。
- 帧率：30/60/90/120fps为请求值，实际接收和解码帧率在显示页查看。120fps启动失败时依次尝试90fps和60fps。静态画面可能减少视频更新，解码帧率不等于显示器刷新率。
- CarPlay界面大小：在CarPlay画面内打开“设置→显示屏→智能缩放显示”。此开关可改变图标、文字和渲染尺寸，与MacPlay窗口大小分别设置。
- 音频：在“音频”页实时调整媒体/通话音量、切换输入/输出设备。音乐信息和播放操作仍使用Mac控制中心。
- 后台：在“连接→应用”设置关闭主窗口时的行为；菜单栏图标可重新打开主窗口、显示CarPlay或退出。
- 捐赠：在侧栏打开“捐赠”，查看微信支付、支付宝和AlipayHK收款码，点击可放大；PayPal按钮会在浏览器打开[捐赠页面](https://paypal.me/RoyRoylyl)。
- 问题反馈：在“关于→日志”点击“导出日志”保存TXT，或点击“导出诊断快照”保存JSON，附上连接方式和具体表现。
